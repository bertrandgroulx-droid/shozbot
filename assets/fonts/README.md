# Fonts

`jetbrains-mono-latin.woff2` is **JetBrains Mono** — the Latin subset, as a
variable font covering weights 300–700 in a single 31 KB file. It is the
Shozbot wordmark and heading face.

It is served from this repo rather than from Google's CDN: one fewer
third-party request, nothing for a visitor's browser to report elsewhere, and
it keeps working if the CDN doesn't.
